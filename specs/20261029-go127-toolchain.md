# Issue #52: align project baseline with Go 1.27.3

## Why

The project has Go 1.27.3 installed locally, but `go.mod`, the test matrix, and
current documentation still describe Go 1.26. The pinned golangci-lint v2.13.2
cannot decode Go 1.27 export data, and gosec v2.29.0 skips SSA analysis on this
toolchain.

## What

- Set Go 1.27.0 as the module language baseline and Go 1.27.3 as the toolchain.
- Test the Go 1.27 baseline and stable in CI.
- Align the pinned golangci-lint and gosec versions with Go 1.27 support.
- Update current Go version references in README and AGENTS.md.

## How

1. Reproduce the pinned linter failure under Go 1.27.3.
2. Update the module directives and pinned compatible linter version.
3. Update CI and current project documentation.
4. Run build, vet, lint, shuffled tests, module tidy, and YAML parsing.

## 遭遇的困難

- golangci-lint v2.13.2 failed to decode Go 1.27 export data (format 5; maximum
  supported format 4).
- gosec v2.29.0 reported package type errors and skipped SSA analysis.
- The Go module proxy returned HTTP 403 because the process-wide VS Code proxy
  was applied to non-GitHub hosts.

## 如何解決

- Confirmed direct access to the Go module proxy succeeds, then bypassed the
  configured proxy only for Go module hosts in the current process.
- Upgraded the pinned tool to golangci-lint v2.15.0, ran `go mod tidy`, and
  verified lint with 0 issues.
- Verified gosec v2.30.0 builds complete SSA analysis and reports 0 issues;
  updated the pinned Taskfile command.

## 最後變動了什麼

- `go.mod` and `go.sum`: set `go 1.27.0` and `toolchain go1.27.3`; upgrade
  golangci-lint from v2.13.2 to v2.15.0 and update its tool dependencies.
- `Taskfile.yml`: upgrade gosec from v2.29.0 to v2.30.0.
- `.github/workflows/test.yml`: use Go 1.27 as the minimum test matrix version.
- `README.md`: update the Go badge and minimum requirement.
- `AGENTS.md`: update the Go modernization range.
- `specs/20261029-go127-toolchain.md`: record Issue #52, changes, and validation.

## 驗證結果

- Go toolchain: `go1.27.3`.
- `go build ./...`: passed.
- `go vet ./...`: passed.
- `go test -shuffle=on ./...`: passed.
- `go mod tidy`: passed; a second run made no changes to `go.mod` or `go.sum`.
- Pinned golangci-lint v2.15.0: 0 issues.
- `task security:all`: govulncheck found no vulnerabilities; OSV found 0
  vulnerabilities; gosec v2.30.0 reported 0 issues.
- GitHub workflow YAML parsed with `gopkg.in/yaml.v3`: YAML OK.
