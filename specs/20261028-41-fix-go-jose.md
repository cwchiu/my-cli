# Issue #41: fix go-jose vulnerability

## Why

Issue #41: OSV reports GHSA-mgcc-cww5-fp2q in the existing indirect dependency `github.com/go-jose/go-jose/v4` v4.1.4.

## What

Update the dependency to the fixed version without changing the project's Go version.

## How

Upgrade to v4.1.6, tidy modules, and run build, vet, lint, tests, and security scans.

## 遭遇的困難

- OSV reported one High vulnerability for go-jose v4.1.4.
- The pinned golangci-lint v2.13.2 cannot decode Go 1.27.3 export data locally.

## 如何解決

- Upgraded the existing indirect dependency to v4.1.6.
- Used golangci-lint v2.15.0 locally without modifying the tool dependency.

## 最後變動了什麼

- `go.mod`, `go.sum`: upgrade go-jose from v4.1.4 to v4.1.6.
- `specs/20261028-41-fix-go-jose.md`: record the issue, changes and verification.

## 驗證結果

- `go build ./...`: passed.
- `go vet ./...`: passed.
- `go test -shuffle=on ./...`: passed.
- golangci-lint v2.15.0: 0 issues.
- `govulncheck ./...`: no vulnerabilities found.
- OSV `scan --lockfile=go.mod`: 0 known vulnerabilities.
- Standalone gosec v2.29.0 was previously found to skip SSA analysis with Go 1.27.3; its exit status alone is not a complete scan.
