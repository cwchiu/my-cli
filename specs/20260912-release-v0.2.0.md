# specs: release-v0.2.0

> 需求來源：使用者指令「發布 v0.2.0」。

## Why

在完成 PR #5（`falcon-cis-export` 子命令與 Web export 格式對齊）與 PR #6（模組化 `AGENTS.md`、補充安全與 API 指南）後，專案已具備完整之 CrowdStrike Falcon K8s CIS 合規匯出能力與產品級安全修復。此時發布 `v0.2.0` 正式版本供使用者與自動化管線下載使用。

## What

- 更新 `CHANGELOG.md`，新增 `[0.2.0] - 2026-09-12` 條目，記錄新增功能（`falcon-cis-export`、Web 格式 CSV 匯出、文件）與變更（升級 grpc 至 `v1.83.2`、模組化規範）。
- 執行本機完整品質關卡驗證（build, vet, lint 0 issues, test, security:all）。
- 提交 PR，通過 GitHub Actions CI 檢查後合併回 `main`。
- 在 `main` 打 annotated tag `v0.2.0` 並 push 至 GitHub，觸發 GoReleaser 發布 Release。

## How

1. 在 worktree `release-v0.2.0` 更新 `CHANGELOG.md` 並撰寫本 spec。
2. 跑完整四關 + 安全掃描（`go build`、`go vet`、`go tool golangci-lint run`、`go test -shuffle=on ./...`、`govulncheck ./...`）。
3. 提交 PR 並確認 CI checks 全綠後合併。
4. 在 `main` 打 tag `v0.2.0`：`git tag -a v0.2.0 -m "v0.2.0: falcon-cis-export subcommand, CIS CSV export, and security updates"`。
5. `git push origin v0.2.0` 觸發 Release workflow，監控直至 Release 完成。

無。所有功能與安全修復已在前序 PR #5 與 PR #6 經過完整驗證並解決。
