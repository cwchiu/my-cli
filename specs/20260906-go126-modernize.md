# 20260906 — chore/go126-modernize

## Why

路線圖工作項 2（2026-09-06 審核）。兩處技術債：

1. `cmd/my-cli/root.go` 的 `errors.As` 帶有 `//nolint:modernize`，理由寫著
   "requires Go 1.26; project targets Go 1.25"——但專案現在是 Go 1.26
   （go.mod `go 1.26.0` + `toolchain go1.26.8`），nolint 理由已過期。
   AGENTS.md §12 現代化備忘明確列出 `errors.AsType[T]`（1.26+）應直接使用。
2. `go tool golangci-lint run` 每次出現棄用警告：
   `[formatter] gofumpt: 'extra-rules' is deprecated, please use 'extra.group-params' instead.`
   ——警告混在 lint 輸出裡會掩蓋真實問題，應消除。

## What

- `root.go`：`errors.As(err, &notFound)` → `errors.AsType[viper.ConfigFileNotFoundError](err)`，
  刪除過期 `//nolint:modernize`。
- `.golangci.yml`：`settings.gofumpt.extra-rules: true` → 新 `extra` 設定
  （`group-params` / `extra-rules` / `modify-value-receiver` 全開，語意等價於舊 `extra-rules: true`）。

非目標：不動其他 lint 設定、不動其他代碼（`errors.New`/`errUsage` 等保留）。

## How

1. worktree `chore/go126-modernize` 自 main（b66b613）。
2. 改 root.go（Low 風險：語意等價變換，既有測試覆蓋 initConfig 錯誤路徑）。
3. 改 .golangci.yml；以 `go tool golangci-lint config verify` + 重跑 lint 確認警告消失。
4. 四關 + YAML 第五關。

## 遭遇的困難

- 棄用警告只寫 `please use 'extra.group-params' instead`，但未說明 YAML 結構；
  官方文件頁（golangci-lint.run formatters/gofumpt）404，無法直接查設定格式。
- `errors.AsType` 回傳 `(T, bool)` 而非 `errors.As` 的填值模式，直接照抄舊邏輯會編譯失敗。

## 如何解決

- 以 GitHub code search 查 golangci/golangci-lint 原始碼
  （`pkg/config/formatters_settings.go`、`.golangci.reference.yml`、
  `pkg/golinters/gofumpt/testdata/gofumpt_with_extra.yml`）確認新 schema：
  `settings.gofumpt.extra: { group-params, clothe-returns, balance-calls }`；
  舊 `extra-rules: true` 的警告對應項為 `group-params`，故只開該項（保守等價，
  不順手開啟 clothe-returns/balance-calls 造成大範圍重排）。
- 改寫為 `if _, ok := errors.AsType[viper.ConfigFileNotFoundError](err); !ok`，
  語意與原 `errors.As` 完全等價；`errors` import 仍被 `errUsage = errors.New` 使用，保留。

## 最後變動了什麼

- `cmd/my-cli/root.go`：`initConfig` 的 `errors.As(err, &notFound)` →
  `errors.AsType[viper.ConfigFileNotFoundError](err)`，刪除過期
  `//nolint:modernize`（理由「project targets Go 1.25」已不符現況）。
- `.golangci.yml`：`formatters.settings.gofumpt.extra-rules: true` →
  `extra.group-params: true`（附註解說明棄用對應），消除每次 lint 的
  `level=warning ... 'extra-rules' is deprecated` 輸出。
- `specs/20260906-go126-modernize.md`：本紀錄。
