# 20260906-fix-eol — 修復 Windows CRLF 行尾導致 lint 誤報

## Why

合併 `feat/add-lint-config`（`5be268f`）回 `main` 後，在主 repo 重跑 `go tool golangci-lint run` 出現 **5 個 gofumpt 錯誤**（每個 `.go` 檔「File is not properly formatted」）。剛立的 lint 門檻（AGENTS.md §10.2 第 5 條）在 main 上不通過，必須修復。

根因：Windows 的 `core.autocrlf=true` 會在 checkout 時把 LF 檔案轉成 CRLF。worktree 裡的檔案是我直接編輯的（保持 LF）所以 lint 通過；合併後主 repo 重新 checkout，`.go` 檔被轉成 CRLF，gofumpt 要求 LF 而誤報。

## What

- 新增 `.gitattributes`：宣告 `*.go`、`*.yml`、`*.yaml`、`*.md`、`*.mod`、`*.sum` 為 `text eol=lf`（跨平台強制 LF）；`*.bat`/`*.cmd`/`*.ps1` 為 CRLF；圖片為 binary。
- 將工作區既有 CRLF 檔案轉回 LF（9 個：`.gitignore`、`.golangci.yml`、`AGENTS.md`、`Taskfile.yml`、`go.mod`、`go.sum`、specs ×2、`.gitattributes` 本身）。
- 非目標：不改任何程式邏輯；不調整 `.golangci.yml` 內容。

## How

1. 從 `main`（`5be268f`）建立 worktree `fix/eol`。
2. 寫入 `.gitattributes`（LF 為主、Windows 腳本 CRLF、二進位不轉換）。
3. `git add --renormalize .`——index 內容本來就是 LF（i/lf），renormalize 無 diff，**真正問題在工作區檔案**。
4. 用 PowerShell 位元組級轉換（`ReadAllBytes` → 去 `\r\n` → `WriteAllText` UTF-8 無 BOM）將 9 個 CRLF 檔案轉為 LF。
5. `git ls-files --eol` 驗證全部 `w/lf`；lint/test/build 全綠後 commit。

## 遭遇的困難

1. **`git add --renormalize .` 沒有產生任何 diff**：以為 renormalize 能解決，實際上 index 一直是 LF（`i/lf`），CRLF 只存在於工作區（`w/crlf`）——renormalize 修的是 index，不是工作區。
2. **`git diff` 顯示不出行尾變化**：`autocrlf=true` 下 diff 比對前會先做行尾正規化，工作區 CRLF→LF 的轉換在 diff 看起來是「無變化」（`--numstat` 為空），但 `git status` 卻列出 M——非常誤導。
3. **PowerShell `Join-Path`/相對路徑問題**：`[System.IO.File]::ReadAllBytes(".gitattributes")` 以相對路徑呼叫 .NET API 時解析到別的目錄（`D:\tmp\my-cli`），需用 `Join-Path (Get-Location) $f` 絕對路徑。
4. **終端輸出吃字**：pwsh 管線多次把 git 輸出吞掉（`Out-File`、`Tee-Object`、`cmd /c` 重導向都失敗），最終以 `$out = git ...; $out.Count` 變數方式取得輸出。

## 如何解決

1. 改用 `git ls-files --eol` 診斷：清楚顯示 `i/lf w/crlf attr/text eol=lf`——index 是 LF、工作區是 CRLF、屬性已生效。確認要修的是工作區檔案本身。
2. 接受「diff 看不到」的事實，以 `git status` + `ls-files --eol` 為準；commit 後以 `git show --stat` 驗證。`.gitattributes` 生效後，未來 checkout 會自動保持 LF，不會再發生。
3. .NET API 一律用絕對路徑（`Join-Path (Get-Location) $f`）。
4. 終端輸出一律先存變數再 `Write-Output`，不依賴管線。

## 最後變動了什麼

| 檔案 | 變更 | 說明 |
|---|---|---|
| `.gitattributes` | 新增 | `*.go`/`*.yml`/`*.yaml`/`*.md`/`*.mod`/`*.sum` 強制 LF；`*.bat`/`*.cmd`/`*.ps1` CRLF；圖片 binary |
| `.gitignore`、`.golangci.yml`、`AGENTS.md`、`Taskfile.yml`、`go.mod`、`go.sum`、`specs/*.md` ×2 | 修改 | 工作區行尾 CRLF → LF（內容不變） |

（`.go` 檔在 `golangci-lint fmt` 時已轉為 LF，與 index 一致故無 diff。）

## 驗證結果

- `git ls-files --eol`：`REMAINING_CRLF=0`（全部 `w/lf`）。
- `go tool golangci-lint run`：**0 issues**（修復前 main 上為 5 個 gofumpt）。
- `go test -shuffle=on ./...`：`ok github.com/cwchiu/my-cli/cmd/my-cli 0.698s`。
- `go build ./...`：無輸出（成功）。
