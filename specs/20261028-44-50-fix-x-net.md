# Issues #44–#50: x/net security update

## Why

OSV Scanner reports seven vulnerabilities against the `golang.org/x/net`
dependency: CVE-2026-97045, CVE-2026-78661, CVE-2026-97032,
CVE-2026-78663, CVE-2026-78669, CVE-2026-78660 and CVE-2026-78659.

## What

Upgrade the existing indirect dependency to a version addressing all seven
alerts, and verify the applicable Go standard-library toolchain separately.

## How

The common fixed version for all seven x/net findings is v0.62.0. Raise the
minimum Go version to 1.26.9 to cover the five HTTP/2 vulnerabilities in the
standard library as well. Go 1.27.2 and later also contain those fixes.

`go mod why -m` shows x/net is needed by the Task tool through go-getter,
Cloud Storage and the Google API transport. `go list -deps ./cmd/my-cli`
does not list an x/net package in the CLI's dependency graph. The CLI does use
the standard library's HTTP client and has a static HTTP server; its server
uses a plain TCP listener rather than configuring TLS. Scanner findings alone
do not establish an exploitable application call path.

## 遭遇的困難

1. The configured proxy returned HTTP 403 while fetching x/net v0.62.0.
2. The first Go 1.26.9 shuffled test run failed without a named failure in the
   captured output. A replay with the same shuffle seed passed.
3. The Taskfile's gosec v2.29.0 reported package type errors and skipped SSA
   analysis when run with Go 1.27.3.

## 如何解決

1. Set `NO_PROXY=*` only in the relevant command processes; no persistent
   proxy settings were changed.
2. Replayed the same shuffle seed and reran the full test suite successfully.
   The cause of the initial failure was not established.
3. Reran the same gosec task with Go 1.26.9; all packages were analyzed and
   the SARIF report contained no findings.

## 最後變動了什麼

- `go.mod` and `go.sum`: x/net v0.58.0 → v0.62.0 and compatible x/* indirect
  dependency upgrades; minimum Go version 1.26.0 → 1.26.9. `go mod tidy`
  removes the redundant toolchain directive.
- `README.md`: state the new minimum Go version.
- This file: record Issues #44–#50, the dependency investigation and checks.
- The associated commit is available in the linked PR history.

## 驗證結果

- Go 1.27.3: `go build ./...`, `go vet ./...`,
  `go tool golangci-lint run` (0 issues), `go test -shuffle=on ./...`,
  `go mod verify`, and an idempotent `go mod tidy` passed.
- Go 1.26.9: `go build ./...`, `go vet ./...`,
  `go tool golangci-lint run` (0 issues), and `go test -shuffle=on ./...`
  passed.
- `govulncheck ./...`: no vulnerabilities found, using Go 1.27.3.
- OSV Scanner v2.5.1 on `go.mod`: 300 packages, 0 known vulnerabilities.
- Taskfile gosec v2.29.0 on Go 1.26.9: SARIF report has 0 findings; the task
  uses `-no-fail`, so the report was inspected explicitly.
- Windows local tests do not use `-race`; CI is configured to run race tests.
